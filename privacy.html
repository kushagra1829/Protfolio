1. THE BOTTOM LINE: ZERO TRACKING

This website does not collect, sell, rent, or monetize your personal data. There are no tracking pixels, no user authentication databases, no session recording tools, and no third-party behavioral advertising scripts embedded on this origin.

2. COOKIES & LOCAL STORAGE

This site does not set any cookies of its own. It uses optional, privacy-respecting client-side Web Audio synthesis and standard browser sessionStorage solely to remember if you skipped the preloader or toggled audio mute during an active browsing tab. No identifier leaves your local browser sandbox.

3. HOSTING & INFRASTRUCTURE

This portfolio is hosted as a completely static site on Cloudflare Pages (Free Tier). Cloudflare may process basic network metadata (IP address, user-agent, timestamp) strictly for DDoS mitigation, edge caching, and DNS security. Optional telemetry is powered by privacy-first Cloudflare Web Analytics, which does not track individuals across sites or utilize cookies.

4. VERIFIED FRONTEND STACK

In the spirit of honest technical documentation, the libraries powering this site are 100% free open-source utilities:

  • Tailwind CSS (CDN) — Brutalist layout tokens & responsive styling
  • GSAP 3 & ScrollTrigger (CDN) — Motion choreography & section animations
  • Lenis (CDN) — Smooth inertial scrolling
  • Google Fonts — Caveat, Archivo Black, JetBrains Mono, Plus Jakarta Sans
  • Lucide Icons — Lightweight SVG icon markers
  • Web Audio API / Tone.js — Procedural transit chimes (disabled by default)
